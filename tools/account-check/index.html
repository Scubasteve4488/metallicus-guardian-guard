Account Check

Look up any XPR Network account. See what it holds and what it does, in plain English.

🔒
No wallet needed. No signing, no seed phrase box. Your browser asks public XPR servers directly, the same way a block explorer does. This site has no server of its own, so the lookup never passes through us.

Letters a–z, digits 1–5, and dots. A leading @ is fine.

What it shows, and what it doesn't

  • Who's behind an account. The chain shows what an account did. It doesn't show who runs it or what they intend.
  • Whether a token it holds is worth anything. Anyone can send any token to anyone, so a token showing up here proves nothing.
  • Its full history. This shows the account as it is right now.
  • Anything off this chain. Other blockchains and exchange accounts don't show up here.

When a server doesn't answer

If every server refuses, the page says the lookup failed. It won't show a zero.

"This account has no liquidity positions" and "the servers didn't answer" mean very different things, so they're never shown the same way.
