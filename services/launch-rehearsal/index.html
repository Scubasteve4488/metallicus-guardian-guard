Launch Rehearsal

Planned

Practise a launch before it's real, so things go wrong on a day when it doesn't cost anything.

What "planned" means

It means we intend to build it and haven't yet.

There's no scope, no list of what you'd get, and no price. Not because we're hiding them, but because they don't exist.

It's listed here so you can see where this is going, rather than finding it announced one day as if it had always been ready.

What has to happen first

  • The three waitlist jobs get done a few times, and timed.
  • We run a rehearsal end to end at least once and write up how it went.
  • We describe the job from that, not from imagination.
