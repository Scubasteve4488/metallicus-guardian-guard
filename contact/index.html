Support boundaries

What you will get

An answer about this site, its tools, its claims, and what a service would and would not cover. A correction, if something here is wrong. A straight answer about what is not built yet.

What you will not get

Unlimited support. Help recovering a wallet or funds. A verdict on whether something is safe or a good investment. Price views. Support for XPR Network, WebAuth, Metal X or any other product — those have their own official help centres, linked from the FAQ.

⚠
You will never be asked for a seed phrase, a private key, a recovery phrase, a wallet password or an API secret. Not here, not in chat, not in an intake, not ever. No page on this site has a field for one. Anyone asking for one while claiming to be this project is impersonating it — and the real operator’s only public name is @Scubasteve4488.
