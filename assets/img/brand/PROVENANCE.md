# Official brand files: provenance

Fetched 2026-10-28 by IAN-CODE (Claude Code on the StandGuard mini PC) for the noindex prototype `/preview/two-eyes/`.

- **Source:** Metallicus's public brand library on Google Drive, linked from https://metallicus.com/company/brand-guidelines.
- **Owner:** a Metallicus / Metal Pay staff account on the `metalpay.co` domain. The address itself is left out: this site's checks refuse personal email addresses, and it isn't needed to trace the file.
- **Sharing:** anyone with the link, reader.
- **Method:** `curl -L -o <name> "https://drive.google.com/uc?export=download&id=<ID>"`.
- **Checks:** each file was checked to start with `<svg` and to contain no script, event handler, foreignObject or external reference.

**Every file is unmodified.** Do not edit, recolour, crop, re-export or animate the parts of any of these files. They may only be shown, moved, scaled or faded as whole images, with the clear space their owner's guidelines require. For XPR Network, that is one glyph width of empty space all round (Metallicus Products Brand Guidelines (Public), XPR Network section, frame 6).
